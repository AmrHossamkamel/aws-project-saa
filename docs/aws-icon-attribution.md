# AWS icon attribution

The architecture diagram embeds AWS service icons from the official **AWS Architecture Icons** package, downloaded from the [AWS Architecture Icons page](https://aws.amazon.com/architecture/icons/) on October 28, 2026. The package release linked by AWS at that time was `Icon-package_07312026`.

AWS says customers and partners may use the icon toolkits and assets to create architecture diagrams and related materials. The draw.io file embeds the SVGs so the diagram opens without a separate icon library or network access. Individual SVG sources are retained in this folder.

The official AWS page also lists [draw.io](https://app.diagrams.net/?splash=0&libs=aws4) among its architecture diagram tools. Product and service names remain trademarks of Amazon Web Services, Inc. This project is an educational example and is not an AWS product endorsement.
